## 0. 한 줄 요약

**생명점수 = S1(CRISM 광물) + S2(SIM3464 지질) 실데이터, 전 칸(100%) 채움.** 미투입으로 남은 과학지표는 **S5(로버 근접) 하나.** S4(물 활동)·S3(염류)는 **설계완료·비적용** — S4는 S1·S2에 이미 반영, S3은 Jezero 염류 희박. 안전(경사·교신)은 DEM 실데이터로 이미 반영.

## 1. 생명점수 지표 투입 현황

| 지표 | 입력 | 출처 | 상태 | 커버리지 |
|---|---|---|---|---|
| **S1** 함수/점토광물 | CRISM 광물 분류맵 | Zenodo 5575824 (Parente·Itoh·Saranathan) | ✅ 실데이터 격자화 완료 | 2,488 / 3,067 칸 (**81.1%**) |
| **S2** 퇴적·델타 맥락 | USGS 지질맵 SIM3464 | Sun & Stack 2020, doi:10.3133/sim3464 | ✅ 실데이터 격자화 완료 | 3,067 / 3,067 칸 (**100%**) |
| **S3** 보존성 염류 | Jezero 희박 | — | 🟦 **설계완료·비적용** | 해당 적음 |
| **S4** 물 활동 | S1·S2에 내재 | — | 🟦 **설계완료·비적용** | 이미 반영 |
| **S5** 로버 현장 근접 | (Perseverance/MSL) | — | ⬜ 미투입 | — |

> 번호 규약: 코드·가중치 기준 **S4 = 물 활동(순위3, ROC 0.157), S3 = 염류(순위4, ROC 0.090)**.

**→ 미투입은 S5 하나. S3·S4는 설계완료·비적용.**
- **S4 물 활동** — S1(점토·함수광물)과 S2(델타·퇴적)가 **모두 물로 형성·퇴적된 지표**라 '과거 물 활동'은 이미 반영됨. 별도 투입 시 같은 물 신호를 이중계산하게 되어 **루브릭·가중치(순위3, ROC 0.157)는 설계로 유지하되 미투입**.
- **S3 보존성 염류** — **Jezero는 염류가 희박**(주 신호가 점토·탄산염·델타)해 변별력이 낮음. **설계는 유지, 투입 안 함.**

## 2. 생명점수(score) 산출 현황

- **방식:** 가용 지표만 재정규화 — `score = Σ(wᵢ·Sᵢ, 투입된 i) / Σ(wᵢ, 투입된 i) / 4 × 100`. (가짜값 안 채움)
- **가중치(ROC 내장 기본):** S1 .457 · S2 .257 · S4 .157 · S3 .09 · S5 .04 → 현재 분모 = .457+.257 = **.714**.
- **커버리지:** score 채워진 칸 **3,067 / 3,067 (100%)** — S2가 전 영역을 덮어 전 칸 산출.
- **분포:** min / 평균 / max = **25 / 42.7 / 100**. (10점 구간: 20점대 1,924칸 · 50점대 341 · 70점대 329 · 80점대 279 · 100점 99)

| 지표 | 채워진 칸 | min/평균/max |
|---|---|---|
| S1 | 2,488 (81.1%) | 값 분포 1점 1,396 · 3점 690 · 4점 402 |
| S2 | 3,067 (100%) | 0.2 / 1.44 / 4.0 (반올림 0:9 · 1:2,526 · 2:74 · 3:70 · 4:388) |
| **score** | **3,067 (100%)** | **25 / 42.7 / 100** |

데모 핀은 하드코딩이 아니라 **그 위치의 격자 score(실데이터)** 를 읽음(반경 800m 내, 밖이면 추정 폴백).

| 핀 | score | 구성 | 출처 |
|---|---|---|---|
| **델타 전선** | **84** | S1=3(점토) + S2=4(델타 팬) | 격자(실데이터) |
| Cheyava 방향 | 25 | S1=1 + S2=1(호저) | 격자(실데이터) |
| Hawksbill Gap | 25 | S1=1 + S2=1 | 격자(실데이터) |
| Séítah | ~30 | S1=1 + S2=1.5 | 격자(실데이터) |

→ 델타 전선만 84점으로 홀로 높아 생명흔적 1순위가 뚜렷. (호저=화성암 반영해 나머지는 25~30점)

## 4. 중요 반영: Jezero floor = S2 1 (Perseverance 실측)

- SIM3464 매핑 당시 "Jezero floor unit"은 퇴적/화성암 혼재로 해석 → 초기엔 S2=2.
- **Perseverance 착륙 후 바닥이 화성암(Máaz 분출암 / Séítah 올리빈-휘석 화성암질)으로 확인** → '퇴적'이 아니므로 **S2 2 → 1 로 하향** (`make_s2.py` `NAME2S2`).
- 영향: 호저 칸 대량이 25점으로 내려가며 score 평균 51.3 → 42.7. 델타 팬(S2=4)은 그대로라 "평범한 화성암 바닥 vs 희귀한 델타 퇴적지" 대비가 선명.

## 6. 재현 방법

```
# S2 래스터 생성 (SIM3464 지질 폴리곤 → S2 0~4)
python make_s2.py          # → data/s2_jezero.tif

# 생명점수 격자 생성 (S1 CRISM + S2 지질 + DEM 경사/교신)
python build_grid.py --dem jezero_dem.tif \
  --crism zenodo_5575824/jezeroFinal.tif \
  --geo data/s2_jezero.tif --geo-scored \
  --out grid.js --clip-km 5 --cell-px 8 --antenna-h 15
```

산출 `grid.js`: 칸≈160m, 기지 5km 클립, 3,067칸. `_meta.score_note` = "score=가용지표 재정규화, 현재 S1(CRISM 점토·탄산염)+S2(SIM3464 퇴적·델타) 기반".
